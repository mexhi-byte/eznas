# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be kind, assume good faith, and remember that the person
on the other side of an issue is usually trying to get their own NAS working at
eleven at night.

## The short version

- Welcome questions, including ones the README already answers. If the README
  answered it and the person still asked, the README is what needs fixing.
- Criticise code, wording and decisions. Do not criticise people.
- No harassment, no slurs, no publishing anyone's private information, no
  sexualised language or imagery. This applies in issues, pull requests,
  discussions, and anywhere else you are representing the project.
- A maintainer may edit, hide or remove anything that breaks this, and may
  block repeat offenders. They will say why.

## Reporting

Write to the maintainer through GitHub: open a private
[security advisory](https://github.com/mexhi-byte/eznas/security/advisories/new)
if it is sensitive, or mention `@mexhi-byte` in a discussion if it is not.
You should hear back within a week.
